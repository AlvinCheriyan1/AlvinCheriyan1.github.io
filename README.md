# Alvin Cheriyan — Portfolio

A responsive, minimalist portfolio built with plain HTML, CSS, and JavaScript.

Open `index.html` in a browser to preview the site. No install or build step is needed.

## Personalize

- Edit `index.html` to update your introduction, projects, interests, and contact link.
- The second project is a clearly labeled placeholder for future work.
- Change the color variables at the top of `styles.css` to adjust the palette.
- Fonts load from Google Fonts, with system fallbacks when offline.

The files can be served directly by GitHub Pages. In the repository’s Pages settings, choose the branch containing these files and the root folder.
